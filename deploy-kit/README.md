# ハンコ工房（デプロイナウ用キット）

`public/index.html` が工房そのものです。これだけを静的サイトとして置いても動きます（親方の講評・鑑定は「オフライン版」になります）。

このキットごと Next.js アプリとして公開すると、`/api/ai` が使えるようになり、
**親方の検分・ボケ・鑑定士の鑑定を本物のAI（Claude）が印面の画像を見て書く**ようになります。

## 公開手順
1. このフォルダを GitHub に push する（`node_modules` と `.next` は除外済み）
2. デプロイナウでこのリポジトリを公開する（Next.js として自動でビルドされます）
3. デプロイナウのダッシュボードで環境変数を設定する
   - `ANTHROPIC_API_KEY` … Claude の APIキー（必須）
   - `HANKO_MODEL` … 使うモデル（省略時 `claude-haiku-5-5`）
4. トップ（`/`）を開くと工房が表示されます（`/index.html` でも開けます）

## Xでのシェア
- 鑑定画面の「Xに投稿する」で、鑑定書の画像を保存してから投稿画面が開きます（本文に `#ハンコ工房` と作品URL入り）。画像は投稿に添付してください。
- トップ（`/`）は `app/route.js` が返していて、`og:image`（`public/ogp.png`）をアクセスされたURLに合わせた絶対URLに書き換えます。URLをポストすると大きいカード画像が出ます。
- `app/page-html.js` は `public/index.html` から自動生成したものです。工房を直したら両方を揃えてください。

## アイコン
- `public/` に、ブラウザのタブ用（favicon-48.png）、iPhoneのホーム画面用（apple-touch-icon.png）、Android・アプリ化用（icon-192/512.png、icon-maskable-512.png、manifest.webmanifest）が入っています。
- トップ（`/`）を返すときに自動で読み込まれます。差し替える時は同じファイル名で上書きしてください。

## 仕組み
- ページは起動時に `GET /api/ai` を呼び、`{"ok":true}` が返ればAIモードになります。
- `POST /api/ai` は工房のプロンプト（「あなたは鹿児島…」で始まるもの）だけを受け付け、画像は1枚・サイズ上限あり、1つのIPから1分10回までに制限しています。
- APIキーはサーバー側の環境変数にだけあり、ブラウザには出ません。

## ローカル確認
```
npm install
ANTHROPIC_API_KEY=xxxx npm run dev
```
